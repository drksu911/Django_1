# Интернет-магазин на Django

Учебный проект интернет-магазина, разработанный в рамках курса по Django. Реализованы базовая структура, главная страница и страница контактов с формой обратной связи.

## Технологии

- Python 3.13
- Django 6.0.2
- Bootstrap 5 (подключён через CDN)
- SQLite (база данных по умолчанию)

## Функциональность

- **Главная страница** — приветствие и примеры товаров (статичные карточки).
- **Страница контактов** — форма обратной связи с полями «Имя», «Email», «Сообщение». Данные сохраняются в базу данных (модель `Feedback`) и выводятся в консоль для отладки. После отправки пользователь видит сообщение об успехе.
- **Навигация** — меню с переключением между страницами с подсветкой активного пункта.
- **Адаптивная вёрстка** с использованием Bootstrap.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/drksu911/Django_1.git
cd название-репозитория
```

### 2. Создание и активация виртуального окружения

```bash
python -m venv venv
source venv/bin/activate      # для Linux/macOS
venv\Scripts\activate         # для Windows
pip install -r requirements.txt
```

### 3. Применение миграций

```bash
python manage.py migrate
```

### 4. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска перейдите по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

## Использование

- **Главная страница** — доступна по `/` или `/home/`.
- **Контакты** — доступны по `/contacts/`. Форма отправляет POST-запрос, данные сохраняются в БД, выводится сообщение об успехе.
